# Muad Alwahidi — KAYAN DESIGNS

موقع بورتفوليو عربي RTL بتصميم سينمائي احترافي.

## المميزات
- تصميم متجاوب للهاتف والكمبيوتر.
- معرض أعمال حقيقي مع فتح الصورة بالحجم الكبير.
- فلاتر للمعرض.
- قائمة جوال.
- مؤثرات ظهور أثناء التمرير.
- قسم خدمات وتواصل.
- SEO وبيانات مشاركة أساسية.

## النشر على GitHub Pages
ارفع الملفات الموجودة في هذا المجلد إلى مستودع GitHub، ثم:
**Settings → Pages → Deploy from a branch → main → /(root) → Save**.

## مهم قبل النشر النهائي
افتح `script.js` واستبدل:
`YOUR_EMAIL@example.com`
بريدك الإلكتروني الحقيقي حتى يعمل نموذج التواصل.

## الصور
الصور الموجودة داخل `assets/` مستخدمة في معرض الأعمال الحالي. يمكنك استبدالها بصورك مع الحفاظ على أسماء الملفات، أو تعديل المسارات في `index.html`.
